# Models

Blockbench (`.bbmodel`) files and textures of the models used by Minepreggo. They are provided so you can create your own skins and textures.

| Folder | Contents |
|---|---|
| [`player/predefined`](player/predefined) | Models and textures for the **predefined player** skin, from non-pregnant to every pregnancy phase (P0 to P10). |
| [`humans`](humans) | Models for the **human** mobs (female and male). |

## Naming conventions

| Name | Meaning |
|---|---|
| `P0` ... `P10` / `_p0` ... `_p10` | Pregnancy phase. Files without a phase are the non-pregnant body. |
| `_naked` | Texture variant **without clothes** (with clothes otherwise). It only changes the texture, never the model. |
| `_extra` | Texture containing only the extra body parts (see [`player/predefined`](player/predefined)). |
| `slim` / `wide` | Arm width: Alex (3 px) or Steve (4 px). |
